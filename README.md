# IT Support Specialist — Portfolio

This repository hosts a simple, static portfolio website that showcases my work and experience as an IT Support Specialist. The live site is available at:

https://portfolio-koskei-13.vercel.app/

Summary
-------

This portfolio presents a concise overview of my technical skills, hands-on projects, and contact information. It's intended for hiring managers and colleagues who want a quick sense of my capabilities in desktop/hardware support, networking, systems administration basics, and end-user support.

Key highlights (summary)
- Role: IT Support Specialist / Technical Support
- Focus areas: troubleshooting, hardware/software  repair, user support, networking basics, and documentation
- Tools & technologies: Windows, Linux, Active Directory, Office 365, remote-support tools, ticketing systems
-
What you will find on the site
- Short bio and professional summary
- List of representative projects and examples 
- Contact details and links to professional profiles

Access the live site
- Visit: https://portfolio-koskei-13.vercel.app/ to see the published site.

Preview locally
- Open `index.html` in your browser, or serve the folder with a lightweight server. Example (Python 3):

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000 in your browser.

Repository structure
- `index.html` — main HTML for the portfolio
- `style.css` — site styling
- `resources/` —  assets
- `LICENSE` — license for repository content
